# Hospital Health Monitoring Robot

Hospital Health Monitoring Robot is an ESP32-based IoT prototype designed to explore how mobile robotic systems could support routine patient monitoring in hospital wards. The project combines sensors, microcontroller programming, wireless communication, and a monitoring interface.

This is an educational prototype and is not a certified medical device. It should not be used for real patient diagnosis, treatment, or clinical decision-making.

## Key Features

- ESP32-based robotic prototype
- Sensor-based monitoring workflow
- Wireless data communication
- IoT-oriented system design
- Prototype demonstration of patient-monitoring support

## System Overview

1. Sensors collect readings.
2. The ESP32 processes the sensor data.
3. Data is transmitted through a wireless connection.
4. The monitoring interface displays the collected information.

- Additional electronic components
